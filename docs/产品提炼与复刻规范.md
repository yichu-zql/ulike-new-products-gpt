# 机会新品库：产品提炼与复刻规范

核对日期：2026-11-01（北京时间）。原页面：https://yichu-zql.github.io/ulike-new-products/#zones 。原仓库：https://github.com/yichu-zql/ulike-new-products ，基准提交 `ef2fa568911441a1ae46d538c416312322fd60de`。本文件先于复刻实施整理。

## 1. 工具定位与目标

这是服务于 Ulike 集团新品机会评估的研究资料库。主要用户是产品、品牌、市场和研发决策人员。核心任务是从女性健康、家用美容及相关护理机会中，判断“哪个机会值得继续研究、适合哪个品牌、凭什么值得做、可以怎样做”。

使用路径：确定视角 → 筛选候选 → 横向比较 → 深入证据和产品概念 → 打开参考来源 → 返回继续比较。它提供立项前的判断材料，不负责采购、立项审批或销售交易。

当前快照：129 个机会，集团视角 112 个，术原专属 17 个（主推 5、次推 12），8 期，最新数据日期 2026-10-28；17 个意向品、2 个未上市项目、127 张内嵌参考图片。数量均从原版 DATA 统计，属于当前版本而非长期规则。

## 2. 信息结构及特点

| 层级 | 内容 | 帮助解决的问题 |
| --- | --- | --- |
| 页头 | 工具定位、数量、期数、最近数据日期 | 当前资料覆盖什么范围？ |
| 吸顶导航 | 专区／新品清单／每期明细；全部／集团／术原视角 | 我在哪、正在看哪一组对象？ |
| 专区 | 术原超导护肤、未上市项目、本期修订入口 | 哪些专题需要重点关注？ |
| 新品清单 | 多条件筛选与宽表比较 | 候选之间有哪些差异？ |
| 每期明细 | 分期行业速览、完整产品卡、证据链接 | 为什么收录、为何推荐、如何转化成产品？ |

特色不是堆积产品，而是把“市场信号—用户需求—品牌适配—产品创新—耗材复购—证据”连成一条判断链。每条产品详情包含人群、卖点、品牌、创新套组、使用步骤、销售平台、宣传可视化方向、规模/增速/需求、推荐理由及来源；部分条目增加需求缺口、上市状态或修订记录。

术原专区围绕“进得去、用得对、坚持得下来”组织产品，增加痛点、推荐层级和创新点；仪器与耗材绑定是其明确的商业方向。未上市专区用预计上市时间、最近核查时间和信息来源承接不确定性。

## 3. 视觉风格

专业、克制、偏编辑型的高密度业务工具。浅灰底 `#F4F5F8`、白色内容面、深灰正文 `#1B1F27`、细灰边框 `#E1E3EA`；酒红 `#8A2F5B` 表示主要操作和重点，青蓝 `#1D5C70` 表示术原，绿色表示推荐或更新，琥珀色表示谨慎或待上市。品牌标签另有稳定语义色。

标题使用 Noto Serif SC／宋体回退，正文使用系统中文无衬线，日期及数量使用 IBM Plex Mono。正文 15px，主标题 30px，区块标题 22px，辅助说明 11–13px。内容最大宽度 1280px。轻容器、6–8px 圆角、细边框、小标签；留白与字号承担主要层级，阴影仅用于吸顶和弹窗等层次。

表格用于准确对比，详情使用“左侧参考图＋右侧字段解释”，不把每个字段拆成独立卡片。主推品横向排列，宣传创意用淡酒红底强调。遵循系统深浅主题与减少动效偏好。小于等于 520px 时筛选为两列、详情变单列、品类横向滚动，宽表在自身容器中滚动。

## 4. 交互规则

- 全局视角影响页头、清单、详情、术原内容及字段；原版未上市专区和本期更新条目按全库计算，不随视角缩小。
- 新品清单默认 9 个筛选维度：意向品、日期、方向、品牌、平台、品类、推荐程度、规模梯队、技术；术原增加层级和痛点。条件取交集，显示“结果数／当前视角总数”，支持清空。
- 清单与每期明细的局部筛选独立。明细包含搜索、日期、判断、层级与分组品类；搜索覆盖资料文本。筛选下拉括号数量是当前视角内数量，不是交叉筛选后数量。
- 点术原入口进入专题，痛点按钮同步到清单痛点筛选；主推卡片直达详情。
- 点“看明细”滚动到对应稳定 ID 并短暂描边。详情被局部筛选隐藏时，重置明细筛选；若不在当前视角，切到全部。清单条件保持，返回清单继续比较。
- 未上市项目以原生 dialog 展开，可点关闭或按 Escape；卡片可跳到对应明细。行业速览使用原生 details 展开，关联产品可下钻。
- 导航随滚动标明当前区块；明细筛选接在主导航下吸顶，依据实际导航高度计算偏移。
- 原版仅在浏览器 localStorage 保存视角。意向品是资料中的预设标签，没有编辑、收藏、云同步、导出或在线 AI 生成功能。

## 5. 数据与技术事实

原仓库只有 `index.html` 和 `.nojekyll`。HTML 内含 CSS、原生 JavaScript、DATA JSON 和 Base64 图片；无框架、无后端、无依赖安装、无仓库内采集脚本或 GitHub Actions。

记录有稳定 `id`；`days` 储存行业速览及关联 ID，`items` 储存完整产品记录。表格摘要来自 `summary`，详细解释来自对应长字段。市场梯队在数据中预先标注，页面不会解析市场规模文本重新计算。声明口径为第一梯队 ≥10 亿美元、第二梯队 1–10 亿美元、第三梯队 <1 亿美元、缺统计单列；边界文字应理解为第二梯队不含 10 亿。

复刻保留源数据，不能视为独立核实了全部市场、医疗功效或监管陈述。某些条目引用上级品类且与梯队表述未必直接对应，后续数据治理需逐条审计，不能在复刻时自行补数字或重分级。

原版显示“每周一上午8:05更新”，但源仓库未提供调度、抓取、校验、发布和失败通知链路。无法据此确认其外部更新任务。副本仅建立代码提交后的自动检查和部署，不宣称自动采集内容。

## 6. 本次一比一复刻边界

保留页面布局、配色、字体、内容顺序、129 条记录、127 张参考图、筛选规则、专区、详情和返回路径。工程层拆分为页面骨架、样式、应用脚本、可读 JSON 数据、静态图片；生成发布目录 `dist`，所有资源使用相对路径，支持 GitHub Pages 项目子路径。

必要差异明确记录：副本用独立视角存储键，避免同域原站串用偏好；副标题改为真实数据截止时间；新增源码溯源、数据校验、构建和发布文档。其余产品体验沿用原版，不增加原版不存在的功能。

验收重点：记录及图片逐条一致、视角数量一致、筛选交集正确、无结果可恢复、详情跳转与返回、未上市弹窗、术原痛点联动、手机宽表容器滚动、部署子路径和资源完整性。来源网站所有外链的业务有效性不属于本次全量复核范围。
